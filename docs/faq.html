Χρειάζομαι λογαριασμό για τη λήψη;

Η λήψη και οι οδηγίες είναι διαθέσιμες δημόσια. Το site έχει σελίδα λογαριασμού για σύνδεση και διαχείριση προφίλ.

Παράγεται το ISO μέσα από την εφαρμογή στα Windows;

Το Linux Studio χρησιμοποιεί WSL 2 για Debian, Ubuntu και Arch. Ξεκινάς τη δημιουργία από την εφαρμογή και παίρνεις το τελικό αρχείο με «Λήψη ISO». Για Fedora χρειάζεται αποκλειστική VM.

Ποιες διανομές υποστηρίζονται;

Debian 13, Ubuntu 24.04 LTS, Arch Linux και Fedora 44. Δες τις επιλογές ανά διανομή.
