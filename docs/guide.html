Ρύθμισε την εικόνα

Άνοιξε το Linux Studio. Επίλεξε διανομή, kernel και desktop. Δώσε όνομα στην εικόνα, διάλεξε γλώσσα και πρόσθεσε τα πακέτα σου.

Δημιούργησε και κατέβασε το ISO

Στα Windows ακολούθησε την προετοιμασία WSL 2 μέσα από το Linux Studio για Debian, Ubuntu ή Arch. Σε Linux άνοιξε την εφαρμογή στη διανομή που έχεις επιλέξει και εγκατέστησε τα εργαλεία, αν χρειάζονται.

Πάτησε «Δημιουργία ISO» και, μόλις ολοκληρωθεί, «Λήψη ISO». Για Fedora απαιτείται αποκλειστική VM.
