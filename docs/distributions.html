Εγκατάσταση σε Linux x86-64

Το ίδιο πακέτο Linux Studio χρησιμοποιείται και στις τέσσερις διανομές. Χρειάζεσαι Node.js 22 ή νεότερο. Από τον φάκελο λήψεων, εκτέλεσε ως κανονικός χρήστης:

tar -xzf linux-studio-linux.tar.gz
cd LinuxStudio
node Linux/install.mjs

Άνοιξε το Linux Studio από το μενού εφαρμογών. Για δημιουργία ISO, χρειάζεσαι σύνδεση στο διαδίκτυο και τουλάχιστον 30 GB ελεύθερου χώρου.
