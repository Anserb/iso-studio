Έκδοση Windows

Εγκαταστάτης .exe για Windows 10 22H2 ή Windows 11 x64. Συμπεριλαμβάνει WSL 2 setup, δοκιμή ISO σε QEMU και εγγραφή USB με επιβεβαίωση διαχειριστή.

Έκδοση Linux

Κατέβασε το πακέτο και πρόσθεσε το Linux Studio στο μενού εφαρμογών. Χρειάζεσαι Node.js 22 ή νεότερο.

Λήψη για Linux ↓ 
tar -xzf linux-studio-linux.tar.gz
cd LinuxStudio
node Linux/install.mjs

Μετά την εγκατάσταση, άνοιξε το Linux Studio από το μενού εφαρμογών.
