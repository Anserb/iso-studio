# Linux Studio

Τοπική εφαρμογή για παραμετροποίηση εικόνων Linux Live για υπολογιστές x86‑64. Η διανομή καθορίζει ποιοι kernel, γραφικά περιβάλλοντα και εργαλεία δημιουργίας είναι διαθέσιμα.

| Διανομή | Επιλογές kernel | Εργαλείο |
| --- | --- | --- |
| Debian 13 | Standard, Real-time | [Debian live-build](https://live-team.pages.debian.net/live-manual/html/live-manual.en.html) |
| Ubuntu 24.04 LTS | Generic, HWE, Low-latency | [Casper](https://manpages.ubuntu.com/manpages/noble/man7/casper.7.html), debootstrap και GRUB |
| Arch Linux | Standard, LTS, Zen, Hardened | [archiso](https://wiki.archlinux.org/title/Archiso) |
| Fedora 44 | Standard, Debug | [Lorax](https://weldr.io/lorax/livemedia-creator.html), σε αποκλειστική VM |

Στην εφαρμογή εμφανίζεται το ακριβές όνομα πακέτου του επιλεγμένου kernel. Η έκδοση του πακέτου προκύπτει από τα αποθετήρια κατά τη δημιουργία. Τα προφίλ Debian, Ubuntu και Fedora προσφέρουν Xfce, GNOME, KDE Plasma ή τερματικό. Το Arch προσφέρει Xfce ή τερματικό.

## Εγκατάσταση σε Linux

Κατέβασε το [πακέτο Linux Studio](https://linuxstudio.pvgaming.uk/linux-studio-linux.tar.gz).
Χρειάζεσαι [Node.js 22 ή νεότερο](https://nodejs.org/en/download) και `xdg-open` για αυτόματο άνοιγμα του browser.
Από τον φάκελο λήψεων, ως κανονικός χρήστης, εκτέλεσε:

```sh
tar -xzf linux-studio-linux.tar.gz
cd LinuxStudio
node Linux/install.mjs
```

Άνοιξε το **Linux Studio** από το μενού εφαρμογών. Άφησε ανοιχτό το τερματικό που εμφανίζεται όσο χρησιμοποιείς την εφαρμογή. Μπορείς επίσης να την ανοίξεις με `~/.local/bin/linux-studio`. Η εγκατάσταση ισχύει για τον λογαριασμό σου και τα ISO αποθηκεύονται στο `~/.local/share/linux-studio/builds` ή στον αντίστοιχο φάκελο κάτω από το `XDG_DATA_HOME`.

### Άνοιγμα από τον πηγαίο κώδικα

Με Node.js 22 ή νεότερο εκτέλεσε από αυτόν τον φάκελο:

```sh
node server.mjs
```

Άνοιξε τη διεύθυνση [127.0.0.1:4177](http://127.0.0.1:4177). Η εφαρμογή ακούει μόνο στην τοπική διεύθυνση.

Σε Linux, το `node Linux/launch.mjs` ανοίγει αυτόματα τον browser σε ελεύθερη τοπική θύρα. Για ανάπτυξη με .NET 10, χρησιμοποίησε `dotnet run --project Linux/ISOStudio.Linux.csproj`.

## Εγκατάσταση στα Windows

Κατέβασε και εκτέλεσε το [LinuxStudioSetup.exe](https://github.com/Anserb/iso-studio/releases/latest) σε Windows 10 22H2 ή Windows 11 συμβατά με x64. Άνοιξε το **Linux Studio** από το μενού Έναρξη. Το setup περιλαμβάνει τα runtimes Node.js και .NET. Η εφαρμογή χρησιμοποιεί το WebView2 των Windows και προσφέρει άνοιγμα στον προεπιλεγμένο browser αν το WebView2 δεν είναι διαθέσιμο. Η απεγκατάσταση γίνεται από **Ρυθμίσεις → Εφαρμογές → Εγκατεστημένες εφαρμογές**.

Στα Windows η δημιουργία για Debian 13, Ubuntu 24.04 LTS και Arch χρησιμοποιεί ξεχωριστή διανομή WSL 2. Αν λείπει το WSL 2, πάτησε **Ενεργοποίηση WSL 2** και ακολούθησε τις οδηγίες των Windows. Μετά πάτησε **Προετοιμασία διανομής**. Αυτό κατεβάζει τη βάση Linux και εγκαθιστά τα εργαλεία δημιουργίας. [Προϋποθέσεις WSL](https://learn.microsoft.com/windows/wsl/install)

## Ενημερώσεις εφαρμογής

Κατά την εκκίνηση, το Linux Studio ελέγχει την τελευταία σταθερή έκδοση στο GitHub. Όταν υπάρχει νεότερη έκδοση, κατεβάζει το αντίστοιχο πακέτο στο παρασκήνιο και επαληθεύει το SHA-256 πριν εμφανίσει την επιλογή εγκατάστασης.

Στα Windows το εγκατεστημένο Linux Studio ανοίγει ξανά μετά την εγκατάσταση. Στο Linux κλείσε και άνοιξε ξανά την εφαρμογή όταν τελειώσει. Αν τρέχεις από τον πηγαίο κώδικα, μπορείς να κατεβάσεις το επαληθευμένο πακέτο από την ένδειξη ενημερώσεων.

## Επεξεργασία στο Visual Studio

Άνοιξε το `ISOStudio.slnx` στο Visual Studio 2026 με το workload **.NET desktop development** και εγκατεστημένο Node.js 22 ή νεότερο στο PATH. Πάτησε **F5** για εκτέλεση. Στο **Solution Explorer → ISOStudio.Windows → app** βρίσκονται τα αρχεία HTML, CSS και JavaScript. Το `Windows/Program.cs` ορίζει το παράθυρο των Windows.

Για να δημιουργήσεις ξανά το setup, εγκατέστησε Inno Setup 6 και εκτέλεσε από τη ρίζα του αποθετηρίου:

```powershell
.\installer\build-installer.ps1
```

Το εκτελέσιμο δημιουργείται στο `release/LinuxStudioSetup.exe`. Ο πηγαίος κώδικας διατίθεται με την [άδεια MIT](LICENSE).

## Εφαρμογές Linux

Στο μενού, κάτω από το **Εργαστήριο ISO**, άνοιξε την ξεχωριστή ενότητα **Εφαρμογές Linux**. Η βιβλιοθήκη περιλαμβάνει 76 εφαρμογές για γραφείο, παραγωγικότητα, gaming, Internet, επικοινωνία, σχέδιο και 3D, βίντεο και ήχο, προγραμματισμό, εργαλεία και εκπαίδευση. Αναζήτησε εφαρμογές, φιλτράρισε κατηγορίες ή πρόσθεσε μια έτοιμη συλλογή στην επιλογή σου.

Το **Install** κατεβάζει και εγκαθιστά την εφαρμογή στον υπολογιστή όπου τρέχει το Linux Studio. Για πολλές εφαρμογές, επίλεξέ τες και πάτησε **Install επιλεγμένων**. Η πρόοδος, τα αποτελέσματα και η καταγραφή εμφανίζονται μέσα στην εφαρμογή. Κράτησέ την ανοιχτή μέχρι να ολοκληρωθεί η εργασία. Μετά την εγκατάσταση, θα βρεις τις εφαρμογές στο μενού του Linux σου.

Η εγκατάσταση χρησιμοποιεί το [Flatpak](https://docs.flatpak.org/en/latest/using-flatpak.html) και το Flathub, με κοινό κατάλογο για Debian, Ubuntu, Fedora, Arch, openSUSE και άλλες διανομές που διαθέτουν Flatpak. Αν λείπει το Flatpak, γίνεται αυτόματη προετοιμασία στις οικογένειες Debian/Ubuntu, Fedora/RHEL, Arch και openSUSE, μέσω PolicyKit ή ήδη επιβεβαιωμένου sudo. Οι εφαρμογές εγκαθίστανται στο προφίλ του κανονικού χρήστη, χωρίς εκτέλεση του Linux Studio ως root. Στην πρώτη προετοιμασία μπορεί να χρειαστεί αποσύνδεση και νέα είσοδος για ανανέωση του μενού. Η διαθεσιμότητα κάθε πακέτου εξαρτάται και από την αρχιτεκτονική του υπολογιστή.

Οι ήδη εγκατεστημένες **εκδόσεις Flatpak** αναγνωρίζονται αυτόματα· οι native ή Snap εγκαταστάσεις δεν ανιχνεύονται από αυτή τη βιβλιοθήκη. Ορισμένα πακέτα συντηρούνται από την κοινότητα, και κάποιες υπηρεσίες ή παιχνίδια απαιτούν λογαριασμό ή αγορά. Στα Windows μπορείς να περιηγηθείς στη βιβλιοθήκη, αλλά για εγκατάσταση στο Linux άνοιξε την εφαρμογή μέσα στο Linux.

## Δημιουργία ISO

Στο βήμα **Περιβάλλον**, διάλεξε desktop και **Προεγκατεστημένη εμφάνιση στο ISO**. Υπάρχουν η προεπιλογή της διανομής και 11 φωτεινά ή σκούρα προφίλ, με κάτω γραμμή εργασιών και μενού εφαρμογών. Η επιλογή εμφανίζεται στη σύνοψη και εφαρμόζεται στην πρώτη είσοδο του νέου χρήστη.

Τα προφίλ υποστηρίζουν κάθε διαθέσιμο συνδυασμό γραφικού περιβάλλοντος και διανομής στον κατάλογο. Το Xfce χρησιμοποιεί Arc και Papirus, το GNOME το Dash to Panel και το KDE εγγενή ρύθμιση του Plasma. Οι προεπισκοπήσεις απεικονίζουν την παλέτα και τη διάταξη. Τα στοιχεία του desktop ακολουθούν την υλοποίηση του αντίστοιχου περιβάλλοντος.

Διάλεξε διανομή, kernel, επιφάνεια εργασίας και πακέτα. Στις εφαρμογές θα βρεις επιλογές για προγραμματισμό (Python, Node.js, Java, εργαλεία C/C++ και Godot), gaming (Steam στο Arch, 0 A.D., SuperTuxKart και DOSBox), γραφείο, δημιουργία και πολυμέσα. Οι διαθέσιμες εφαρμογές και τα ονόματα των πακέτων προσαρμόζονται στην επιλεγμένη διανομή. Πάτησε **Δημιουργία ISO** και, όταν ολοκληρωθεί η καταγραφή, πάτησε **Λήψη ISO**. Χρειάζεσαι σύνδεση στο διαδίκτυο και τουλάχιστον 30 GB ελεύθερου χώρου. Για Fedora χρησιμοποίησε αποκλειστική VM χωρίς δεδομένα που χρειάζεσαι, καθώς το Lorax εκτελεί το Anaconda μέσα στη VM.

Σε Linux χρησιμοποίησε σύστημα x86‑64 που αντιστοιχεί στην επιλεγμένη διανομή. Η εφαρμογή μπορεί να ζητήσει δικαιώματα μέσω PolicyKit για την προετοιμασία και τη δημιουργία. Αν το περιβάλλον σου χρησιμοποιεί μόνο sudo, εγκατέστησε τα εργαλεία παρακάτω και επιβεβαίωσε τη συνεδρία με `sudo -v` στο τερματικό από όπου θα ανοίξεις την εφαρμογή.

### Debian 13

```sh
sudo apt update
sudo apt install sudo live-build debootstrap debian-archive-keyring xorriso squashfs-tools syslinux-common isolinux grub-common grub-efi-amd64-bin
```

### Ubuntu 24.04 LTS

```sh
sudo apt update
sudo apt install sudo debootstrap ubuntu-keyring systemd-container squashfs-tools xorriso mtools grub-common grub-pc-bin grub-efi-amd64-bin
```

### Arch Linux

```sh
sudo pacman -Syu archiso sudo
```

### Fedora 44 σε VM

```sh
sudo dnf install sudo lorax-lmc-novirt
```

Κράτησε ανοιχτή την εφαρμογή όσο τρέχει η δημιουργία. Τα ISO αποθηκεύονται και στον φάκελο εργασίας της εφαρμογής, κάτω από `%LOCALAPPDATA%\linux-studio\builds` στα Windows ή στο `linux-studio/builds` του καταλόγου δεδομένων χρήστη στο Linux. Κάθε δημιουργία έχει δικό της υποφάκελο.

Ο ενσωματωμένος εγκαταστάτης είναι επιλογή του Debian. Η εναλλαγή αγγλικού και ελληνικού πληκτρολογίου σε Arch και Fedora αφορά το γραφικό περιβάλλον. Το επίσημο προφίλ Arch περιλαμβάνει τα δικά του πακέτα firmware και εργαλεία εγκατάστασης.
